# Telegram Bot Project with AI-powered Channel Management

This project uses the GROQ API to create a smart Telegram bot that can manage a channel based on natural language commands from the channel owner and administrators.

## Features
* Automatic recognition of channel owner and administrators
* Ability to execute commands through natural language
* Support for voting and rating the channel
* Ability to delete messages and ban users
* Integration with Railway for easy deployment

## Requirements
* Node.js 16.x
* Telegram Bot API token
* GROQ API KEY

## Setup
1. Create a new Telegram bot and obtain the API token
2. Create a GROQ API account and obtain the API KEY
3. Set up a Railway project and create environment variables for the API tokens
4. Clone this repository and deploy to Railway
